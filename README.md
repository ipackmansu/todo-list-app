# To-Do List App 📝

A modern, feature-rich to-do list application with local storage functionality. Organize your tasks efficiently with priorities, due dates, and search capabilities.

## Features ✨

- ✅ **Add Tasks** - Create new tasks with text, priority level, and due dates
- 🎯 **Priority Levels** - Set tasks as Low, Medium, or High priority
- 📅 **Due Dates** - Assign due dates to keep track of deadlines
- ✔️ **Mark Complete** - Check off tasks when completed
- ✏️ **Edit Tasks** - Modify task text anytime
- 🗑️ **Delete Tasks** - Remove individual tasks
- 🔍 **Search** - Find tasks quickly with the search feature
- 🏷️ **Filter** - Filter by All, Active, Completed, or High Priority tasks
- 📊 **Statistics** - View total, active, and completed task counts
- 💾 **Local Storage** - All tasks are saved automatically in browser storage
- 📤 **Export** - Download your tasks as a JSON file for backup
- 🧹 **Clear Completed** - Remove all completed tasks at once
- 📱 **Responsive Design** - Works perfectly on desktop and mobile devices

## How to Use 🚀

1. **Add a Task**
   - Enter task text in the input field
   - Select a priority level (Low, Medium, High)
   - Optionally set a due date
   - Click "Add Task" or press Enter

2. **Manage Tasks**
   - Check the checkbox to mark a task as complete
   - Click "Edit" to modify task text
   - Click "Delete" to remove a task

3. **Filter & Search**
   - Use filter buttons to view: All, Active, Completed, or High Priority tasks
   - Use the search bar to find specific tasks

4. **Export & Clear**
   - Click "Export Tasks" to download your tasks as JSON
   - Click "Clear Completed" to remove all completed tasks

## Features in Detail 📋

### Priority System
- **Low** - Green badge for non-urgent tasks
- **Medium** - Yellow badge for regular tasks (default)
- **High** - Red badge for urgent tasks

### Local Storage
- Tasks are automatically saved to browser storage
- Data persists even after closing the browser
- No server required

### Search & Filter
- Real-time search across all tasks
- Filter by status (active/completed) or priority
- Combine search and filters for precise results

### Export Feature
- Download tasks as JSON format
- Perfect for backup purposes
- Can be imported into other applications
